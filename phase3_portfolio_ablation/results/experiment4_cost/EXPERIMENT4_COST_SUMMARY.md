## Executive Summary

在固定 `baseline_pred.pkl`（SHA256: `27f0658b...`）、`topk=20`、`n_drop=2`、`hold_thresh=1` 的条件下，仅改变单边交易成本（open_cost = close_cost = 0/1/5/10/20/50 bps，`min_cost=0`），24 组回测显示：**Cost Drag 与 ARR(w/ cost) 严格单调、近似线性**（R²≈1.000），**无锯齿、无 regime-dependent 最优成本**。这与 Exp1–3 的锯齿/路径依赖形成鲜明对照，证实**脆弱性来自选股/持仓路径（信号噪声），而非回测引擎本身**。换手率与 ARR(w/o cost) 在数值上非 bitwise 恒等，但差异随成本比例线性缩放、幅度极小（全样本 turnover 最大差 0.02pp），原因为**账户净值反馈影响后续仓位规模**，非排名改变。全样本在 0 成本下已亏损（-11.07%），不存在"盈亏平衡成本临界点"；恢复期在 50bp 下仍为正（+12.4%）。

### 1.3 min_cost 选择

**采用 `min_cost = 0`**（与 baseline 一致）。

理由：本实验研究**比例费率**敏感性，不引入固定最低佣金；若 min_cost 随费率同比缩放，会混淆"费率效应"与"最低收费效应"。

### 1.4 方法

- 固定 pred，只重跑 PortAnaRecord
- 脚本：`scripts/run_experiment4_cost.py`
- 24 组 = 4 时段 × 6 成本点；各时段独立初始化

## 4. 任务3：核心问题回答

### Q1：Cost Drag 是否严格单调/线性？

| 检验 | 全样本 | 三时段 |
|---|---|---|
| Cost Drag 单调递增 | ✅ 6/6 | ✅ 全部 |
| ARR(w/ cost) 单调递减 | ✅ 6/6 | ✅ 全部 |
| 线性拟合（Cost Drag vs bps） | slope **0.065 pp/bps**, R²=**0.999997** | 同趋势 |

**结论：是。** 本次为 Phase 3 中**最干净、最可预测**的关系；无锯齿，无需路径依赖排查。

### Q2：换手率是否完全一致？

| 指标 | 全样本最大差异 | 判定 |
|---|---|---|
| 日均换手 | 0.00020（0.02pp 量级） | 非 bitwise 恒等，但**极小** |
| ARR(w/o cost) | 0.0015pp（50bp vs 0bp） | 同左 |

差异随成本比例**近似线性缩放**，原因为：更高成本 → 账户净值更快缩水 → `risk_degree` 下后续买入规模微变 → 换手与 gross return 路径轻微偏移。**选股排名与 n_drop 决策未变**；这不是 Exp2/3 型的路径依赖分叉。

### Q3：盈亏平衡成本临界点？

| 时段 | 0 成本 ARR(w/o) | 是否曾 ≥0（w/ cost） | 备注 |
|---|---|---|---|
| 全样本 | -11.07% | 否（全程亏损） | 无 breakeven bps |
| 2020Q1 | -108.32% | 否 | |
| 恢复 | +14.22% | **是**（全程为正） | 50bp 仍 +12.4% |
| 2022-23 | -11.16% | 否 | 50bp 时 -25.5% |

全样本在**零成本下已显著亏损**，不存在"从盈亏平衡变亏损"的临界点；成本只在此基础上**线性叠加** drag（baseline 1bp 仅 0.07pp）。

"明显恶化"参考：全样本 1bp→50bp 额外损失 **3.26pp**（-11.13%→-14.33%）。

### Q4：是否出现锯齿/路径依赖？

**否。** 六组 Cost Drag 与 ARR 均为**光滑单调曲线**，无方向翻转，无 regime-dependent"最优成本"。

**对照意义**：Exp1–3 的锯齿与路径依赖**不能**归因于回测框架本身；成本维度验证了引擎在"不影响选股"的参数上行为符合理论预期。

---

## 5. 最终结论

1. **交易成本敏感性符合直觉**：Cost Drag ∝ 费率，ARR(w/ cost) 单调下降，近似线性
2. **与构造参数消融形成对照**：TopK/n_drop/hold_thresh 的锯齿与路径依赖是**信号噪声 × 组合路径**现象，非通用回测噪声
3. **min_cost=0** 是正确选择：隔离比例费率效应
4. **全样本亏损主因非成本**：0 成本下仍 -11.07%；baseline 1bp drag 仅 0.07pp（与 Exp1 8pp 缺口拆解一致）
5. **Phase 3 论证链闭合**：三角验证（Exp1–3）+ 成本对照（Exp4）→ 系统性脆弱性根源在**信号噪声**，成本为次要线性项
